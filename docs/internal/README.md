# Internal docs

Planning notes, session logs, draft roadmaps, and one-off reports. These
live under `docs/internal/` (not `docs/`) to keep the main docs directory
focused on material a hackathon judge, contributor, or operator needs to
understand or run the project.

Nothing here is authoritative user-facing documentation. When a topic
matures out of planning into something users or contributors should see,
it moves up to `docs/` with a clean rewrite.

## What's here

| File | What it is |
|------|-----------|
| `SESSION_PLAN.md` | Internal session-by-session build log. |
| `SKILLS-IMPLEMENTATION-PLAN.md`, `SKILLS-ROADMAP.md` | Product/engineering skill-matrix planning. |
| `LEVEL3-ROADMAP.md` | Hackathon Level 3 checklist — retained for audit, superseded by the submission checklists in the main `README.md`. |
| `TWITTER_AUTOMATION.md` | Internal social automation notes. |
| `GOOGLE_FORM_SPEC.md` | User-feedback form question spec (referenced from `README.md` for provenance). |
| `LIGHTHOUSE_REPORT.md` | One-off performance audit. |

If you're reviewing the project as a judge or contributor, start with
the root `README.md` and the shortlist in `docs/` — not here.
